Архитектура

Модули без циклических зависимостей

nginx отдаёт статику и перезаписывает X-Real-IP — на нём держится rate-limit, подмена XFF не проходит.
FastAPI собран из независимых модулей: security, auth, schemas, llm_provider, db, mocks.
LLM-провайдер меняется одной переменной. Anthropic идёт отдельной веткой: system отдельным полем, свой заголовок и суммирование usage.
Wan вызывается по сцене, статус опрашивается, клипы скачиваются с ограничением 60 МБ каждый.
SQLite в WAL и списание одним UPDATE … WHERE balance >= n: гонки и овердрафт исключены.

Запуск

Одна команда до работающей студии

1
Скопируйте .env.example в .env. Ключи можно оставить пустыми — студия откроется в DEMO.
2
Поднимите стек. Именованный volume для /data снимает проблему прав на SQLite.
3
Прогоните make verify — 38 проверок покрывают SSRF, биллинг, схему LLM, историю и rate-limit.
4
Для прода задайте JWT_SECRET, свой домен в CORS_ORIGINS и включите HTTPS.
Смена модели
LLM_PROVIDER=anthropic ANTHROPIC_API_KEY=sk-ant-…

Доступно: qwen · openai · anthropic · groq · deepseek · openrouter.

Защита и честность

Что закрыто и что честно признано

🛡

SSRF-фильтр

Приватные, loopback, link-local и reserved адреса отклоняются. Редиректы проверяются на каждом шаге, лимит 3 перехода и 3 МБ ответа.

⚖️

Атомарный биллинг

Списание одним UPDATE с условием. Параллельные запросы не могут увести баланс в минус. Резерв покрывает полный ответ модели.

✅

Схема ответа

Pydantic проверяет каждый ответ LLM. При провале — повтор с текстом ошибки. Кривой JSON не ломает интерфейс.

🚦

Rate limit

Доверие только X-Real-IP от nginx. Отдельный жёсткий лимит на /api/auth/* против брутфорса.

📊

Частотность — оценка

Цифры спроса даёт модель, а не Wordstat. Это помечено в UI и в ответе API. Для закупок подключайте реальный источник.

🧩

Graceful degradation

Нет ключей — демо. Нет ffmpeg — ZIP с командой. Нет clipboard API — fallback. Нет html2pdf — печать. Ядро не ломается.
