офлайн-кэш: —
1Android · Chrome: меню «⋮» → «Добавить на главный экран» → «Установить». Если пункта нет — «Создать ярлык».
2iPhone · Safari: кнопка «Поделиться» (квадрат со стрелкой) → «На экран «Домой»» → «Добавить».
3Яндекс.Браузер: меню «⋮» → «Добавить ярлык» / «На главный экран».
4Иконка появится на рабочем столе. Открывайте студию только через неё — адрес всегда правильный.

Если раздел не открывается
• Репозиторий должен быть Public, иначе Pages не отдаёт сайт. • В Settings → Pages выбран Source: GitHub Actions. • Файл лежит по пути .github/workflows/pages.yml — папка с точкой впереди. • После коммита сборка идёт 1–2 минуты, вкладка Actions должна быть зелёной. • Офлайн открываются только те разделы, которые вы хотя бы раз открыли онлайн.
