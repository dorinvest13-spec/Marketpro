Готовлю установку

Страница собирает PNG-иконки 192 и 512, подставляет манифест с абсолютным адресом запуска и включает офлайн-кэш. Каждая проверка ниже показывает, что именно мешает установке, и чинится кнопкой.

готовность: — манифест: — офлайн: — иконки: —
1Android · Chrome: меню «⋮» справа сверху → Установить приложение. Если такого пункта нет — Добавить на главный экран или Создать ярлык. Ярлык даёт ту же иконку и тот же адрес.
2Яндекс.Браузер: меню «⋮» → Добавить ярлык / На главный экран.
3Samsung Internet: меню «☰» → Добавить страницу в → Главный экран.
4iPhone · Safari: кнопка Поделиться (квадрат со стрелкой вверх) → На экран «Домой» → Добавить. Safari не ставит из манифеста — это единственный путь.
5Иконка появилась на рабочем столе. Открывайте студию только через неё — адрес всегда правильный, старый сайт не подставится.
